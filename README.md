## Modulo di download
Il modulo in `/whitepaper/` invia i contatti a un servizio esterno.
L'identificativo va inserito in `whitepaper/index.html`, nella variabile `FORM_ID`.
Finché è vuota il PDF si scarica ma il contatto non viene registrato.
